# Optional zero-install contract

This short contract can be pasted into an existing chat or note. Customize it
for the task; omit irrelevant sections. It is an instruction, not a permission
system, persistent registry, or proof of compliance.

> Follow the currently accepted goal, requirements and constraints. Treat a new
> requirement as an addition unless modification or replacement is explicit.
> Use only the methods relevant to this task. Preserve mandatory conditions;
> disclose unresolved conflicts instead of silently choosing one.
>
> Goal: [desired outcome]
>
> Done when: [observable acceptance criteria]
>
> Applicable principles: [user-selected methods and activation conditions]
>
> Allowed scope and stop conditions: [paths/actions, approval boundaries]
>
> Verification: [appropriate checks and evidence; mark unexecuted checks unknown]
>
> Outputs: [deliverables and locations]

Do not load every policy pack into every conversation. Where the agent supports
AGENTS.md, the native project workflow can render a task-specific equivalent.
